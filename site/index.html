Type a time. Everyone sees their own.

Magic Time turns plain English like “fri 8pm PT” into a Discord timestamp code. Paste the code in a message, and each person reading it sees the time in their own time zone.

You type
fri 2pm eastern
Magic Time copies
<t:1790964000:F>
Discord shows you
Friday, October 2, 2026 at 2:00 PM
  • Los AngelesFriday, October 2, 2026 at 11:00 AM
  • LondonFriday, October 2, 2026 at 7:00 PM
  • TokyoSaturday, October 3, 2026 at 3:00 AM

Where it works

Mac

Lives in the menu bar. Press ⌃⌥⌘T in any app, type a time, press ↩, and paste.

iPhone and iPad

Type a time and tap a format to copy it. Also in Spotlight, Siri, Shortcuts, and the Action button.

Command line

The magic-time command uses the same reader, so every version gives the same answer.

Reads the way you talk

Days, dates, times, time zones, and holidays across many calendars. If Magic Time can’t be sure what you meant, it says so instead of guessing.

  • tomorrow 9:30am
  • tmrw 8p
  • 3rd friday in may at 6pm
  • friday after next
  • in 2 hours
  • 7pm london
  • lunar new year 7pm PT
  • erev rosh hashanah 6pm
  • last friday of the month

Support

Which time zone does Magic Time use?

The one you pick in the app; it starts on Eastern time. A time zone in what you type always wins, so “6pm PT” means Pacific time whatever the setting is.

Why do I see a note instead of a time?

Magic Time never guesses. Some holidays don’t have one agreed date, like Vesak or a plain “Eid,” and some years almanacs disagree. The note explains why and, when it can, names the possible dates so you can type the one you mean.

How do I paste the code into Discord?

Copy a format in Magic Time, then paste it anywhere in a Discord message. Discord replaces the code with the time when the message is sent.

Can I turn a code back into a date?

Yes. Paste a <t:…> code or a Unix timestamp into Magic Time and it shows the date and time it stands for.

Does Magic Time need an internet connection?

No. Everything happens on your device, including holiday dates, and nothing is sent anywhere. See the privacy policy.

Still stuck, or found a time Magic Time reads wrong? Report it on GitHub.

Include exactly what you typed and the time zone you picked, so the problem can be reproduced.
