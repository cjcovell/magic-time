# Security

Magic Time runs entirely on your device. It makes no network connections, has no accounts, and
stores only your time-zone choice (and, on Mac, the format you last highlighted).

## Reporting a problem

If you find a security problem, please report it privately rather than in a public issue:
open the repository’s **Security** tab and choose **Report a vulnerability**. Include what you
found, how to reproduce it, and which platform and version you used.

You’ll get a reply in that report. Fixes ship in the next App Store update and in this repository.

## Supported versions

Only the latest release on the App Store and the `main` branch get security fixes.
